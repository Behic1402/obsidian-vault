# Regeln für Claude in diesem Vault

Dies ist der persönliche Obsidian-Vault von Behic. Claude ist das Gedächtnis:
**Alles, was Behic an Informationen nennt, wird hier gespeichert**, ohne dass extra darum gebeten werden muss.

## Zu Beginn jeder Sitzung
1. `10 Über mich/Über mich.md` lesen, damit du den Kontext kennst.
2. Bei Bedarf passende Notizen per Suche (grep) nachschlagen, bevor du nachfragst.

## Speichern
- Neue Fakten über Behic (Vorlieben, Ziele, Gewohnheiten, Daten) → `10 Über mich/`.
- Projekte und Vorhaben → `20 Projekte/<Projektname>.md`.
- Personen → `30 Personen/<Name>.md`.
- Wissen, Anleitungen, Recherchen → `40 Wissen/`.
- Tagesereignisse und Gespräche → `50 Journal/JJJJ-MM-TT.md`.
- Unklar, wohin? → `00 Inbox/`.
- Bestehende Notiz erweitern statt Duplikat anlegen. Veraltete Infos korrigieren, nicht nur ergänzen.
- Obsidian Flavored Markdown: Frontmatter (`tags`, `aliases`, `erstellt`, `aktualisiert`), `[[Wikilinks]]` zwischen Notizen.
- Sprache: Deutsch.
- Keine Passwörter, PINs, Kontonummern oder Gesundheitsdaten ohne ausdrückliche Bitte speichern.

## Nach jedem Speichern
Commit mit kurzer Nachricht (z. B. `notiz: Projekt X ergänzt`) und Push auf `main`,
damit Obsidian Git es auf alle Geräte synchronisiert. Kurz in einer Zeile sagen, was gespeichert wurde.
